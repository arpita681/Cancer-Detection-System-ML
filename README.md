# Cancer Detection System using Machine Learning

A machine learning-based Cancer Detection System designed to classify tumors as benign or malignant using predictive analytics and classification algorithms.

## Features
- Data preprocessing and cleaning
- Model training and evaluation
- Tumor classification
- Performance comparison of ML models
- Prediction using healthcare dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- XGBoost
- Jupyter Notebook

## Machine Learning Models
- Logistic Regression
- Random Forest
- XGBoost

## Dataset
Breast Cancer Wisconsin Dataset

## Objective
The objective of this project is to develop a machine learning model capable of detecting cancer efficiently using medical data analysis techniques.

## Output
The system predicts whether a tumor is:
- Benign
- Malignant
